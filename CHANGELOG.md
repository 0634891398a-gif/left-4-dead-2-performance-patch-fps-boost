# CHANGELOG.md

## [v2.4.1] - 2023-10-15
### Added
- Enhanced support for NVIDIA Reflex to reduce input latency during gameplay.
- New graphics optimization settings for the "Turtle Rock" engine, allowing for better performance on low-end systems.

### Fixed
- Addressed crashing issues when launching on Windows 11.
- Resolved frame drops occurring in "The Passing" campaign when playing with a full lobby.
- Fixed a bug that would cause visual artifacts in the "Dark Carnival" map under certain lighting conditions.

### Updated
- Optimized AI pathfinding for Special Infected, resulting in smoother enemy navigation.
- Tweaked the performance of "Common Infected" animations, reducing CPU load during intense firefights.

## [v2.3.0] - 2023-07-10
### Added
- Introduced a new performance benchmarking feature to help players assess their in-game performance metrics.
- Support for AMD FSR (FidelityFX Super Resolution) for improved frame rates on supported hardware.

### Fixed
- Resolved issues causing the game to freeze during "No Mercy" map end credits.
- Fixed a latency issue affecting voice chat under certain network conditions.
 
### Updated
- Improved texture streaming for "Blood Harvest" to reduce stuttering during gameplay.
- Adjusted lighting effects in "Swamp Fever" to enhance visual fidelity without compromising performance.

## [v2.1.0] - 2023-03-22
### Added
- New toggle for dynamic shadow settings in the "Dead Center" environment for enhanced frame rate on lower-end machines.
- Integration of a new server-side performance monitoring tool for matchmaking stability.

### Fixed
- Corrected a memory leak issue in "The Sacrifice" that would gradually degrade performance during long sessions.
- Fixed an issue where certain custom mods would lead to unexpected crashes during gameplay.

### Updated
- Enhanced network performance for game hosting, reducing lag and sync issues.
- Adjusted particle effects in "The Parish" to minimize frame drops during intense horde moments.

## [v2.0.0] - 2023-01-10
### Added
- Major overhaul of the game engine to improve overall performance and stability.
- New video settings menu with presets for low, medium, and high performance tailored to various hardware configurations.

### Fixed
- Resolved crashes related to DirectX 11 compatibility
