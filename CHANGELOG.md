# CHANGELOG.md

## [v2.4.1] - 2023-10-15
### Improvements
- Enhanced rendering performance in the "Dead Center" campaign, resulting in smoother gameplay during intense moments.
- Optimized the AI Director's decision-making algorithms to reduce CPU overhead during large horde encounters.
- Improved object loading times in the "Dark Carnival" map, minimizing lag during the initial levels.

### Fixes
- Fixed a memory leak that occurred when spawning Common Infected, which could lead to crashes over extended play sessions.
- Resolved an issue where sound effects would stutter consistently in the "The Passing" map.
- Corrected an occasional desync issue in multiplayer games when a Tank was spawned.

## [v2.3.0] - 2023-08-01
### New Features
- Introduced dynamic resolution scaling to improve frame rates during high-action scenes, particularly in "No Mercy."
- Added a new "Performance Mode" graphic setting that optimizes visuals for better frame rates on lower-end hardware.
  
### Improvements
- Enhanced texture streaming to minimize loading times while switching between areas in campaigns like "Swamp Fever."
- Improved server performance, leading to faster connection times and reduced ping in matchmaking.

### Fixes
- Fixed a bug causing visual artifacts in the "Hard Rain" campaign during rain effects.
- Addressed an issue where the game would hang upon entering the "Versus" mode in certain maps.

## [v2.1.0] - 2023-05-17
### New Features
- Added support for DirectX 12, offering improved graphics and performance optimizations.
- Introduced a new local performance monitoring tool, providing metrics like fps, memory usage, and CPU load.

### Improvements
- Fine-tuned the spawning mechanics for Special Infected to reduce frame drops during high-intensity moments.
- Optimized particle effects across various campaigns, especially during the finale sequences.

### Fixes
- Resolved a critical bug causing players to experience crashes when entering "Survival" mode.
- Fixed networking issues that led to packet loss in cooperative play and smoother performance overall.

## [v2.0.0] - 2023-03-10
### New Features
- Major overhaul of the graphics engine, leading to significant performance improvements on modern hardware.
- Introduced customizable graphics settings, allowing players to adjust shadows, textures, and fidelity.
